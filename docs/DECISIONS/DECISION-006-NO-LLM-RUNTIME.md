# DECISION-006 — Le runtime ne dépend pas d'un LLM

**Date :** 2026-10-02  
**Statut :** ADOPTED

## Décision
Claude, Codex ou un autre LLM ne sont pas nécessaires dans le chemin critique H24.

## Usage LLM
Développement, audit, tests, documentation, analyse d'expériences et génération d'hypothèses.

## Runtime
Données + moteur SNN + reward/outcome + replay + risque + exécution + persistance + observabilité.

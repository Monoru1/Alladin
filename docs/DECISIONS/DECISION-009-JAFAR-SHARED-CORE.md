# DECISION-009 — Jafar réutilisera le core Alladin

**Date :** 2026-10-02  
**Statut :** ADOPTED

## Décision
Jafar ne sera pas une seconde architecture reconstruite de zéro.

Il réutilisera autant que possible :
- SNN/learning core ;
- replay/experiments ;
- journal ;
- observabilité ;
- cockpit ;
- formats canoniques.

## Différences attendues
Adapters exchange, microstructure crypto, funding, fonctionnement 24/7, types d'ordres et règles de risque adaptées.

Le partage du core ne signifie pas que les paramètres appris sur FX sont automatiquement valides en crypto.
